# 05_final — 最終完成版置き場

## このフォルダの用途
入稿・公開用の最終完成ファイルを置く場所。
ここにあるファイルが「納品物」。

## 置くもの例
- 最終HTML（例: `final_sns-management-roadmap.html`）
- 公開前チェックリスト（例: `公開前チェックリスト.md`）
- メタ情報まとめ（タイトル・ディスクリプション・OGP等）

## 注意
- 04_draft から「完成」と判断したファイルだけコピーする
- このフォルダのファイルを直接編集しない（編集は draft に戻る）
- 公開後の修正履歴もここに記録しておくと良い
