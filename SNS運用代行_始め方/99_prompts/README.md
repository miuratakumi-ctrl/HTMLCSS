# 99_prompts — AIプロンプト集置き場

## このフォルダの用途
記事制作で使用・テスト・改善したAIプロンプトを保管する場所。
次の記事制作でそのまま再利用・改良できる状態にしておく。

## 置くもの例
- 構成生成プロンプト（例: `構成生成プロンプト.md`）
- 本文修正指示（例: `本文修正プロンプト.md`）
- E-E-A-T強化指示（例: `EEAT強化指示.md`）
- CTA改善プロンプト（例: `CTA改善プロンプト.md`）
- AI臭除去チェックプロンプト（例: `AI臭チェックプロンプト.md`）

## 注意
- プロンプトには「使った日付」「効果があったかどうか」のメモも添える
- 効果がなかったプロンプトも残しておく（同じ失敗を繰り返さないため）
