# 02_research — リサーチ結果置き場

## このフォルダの用途
競合調査・検索意図分析・E-E-A-T調査など、
リサーチして整理した分析ファイルを置く場所。

## 置くもの例
- 競合上位記事の比較表（例: `競合比較表.md`）
- 検索意図の整理メモ（例: `検索意図分析.md`）
- E-E-A-T強化ポイントまとめ（例: `EEAT調査.md`）
- 検索ボリューム・難易度データ（例: `キーワード調査結果.md`）
- ユーザーの悩み・質問収集（例: `ユーザーの悩みメモ.md`）

## 注意
- 01_input の素材を分析・整理したアウトプットをここに置く
- 構成案を作り始めたら 03_structure に移行する
