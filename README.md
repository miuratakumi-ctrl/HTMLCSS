# CSV 記事集計ツール

## このツールの目的

GA4・GSC・expected_pv の3つの CSV を `input/` フォルダに置いて `main.py` を実行するだけで、  
記事URL単位の集計表（`output/report.csv`）を生成します。  
毎回同じ列順で出力されるため、Googleスプレッドシートへの貼り付けをそのまま定型化できます。

---

## フォルダ構成

```
プロジェクトルート/
├── input/
│   ├── ga4.csv               ← GA4 からエクスポートしたCSV
│   ├── gsc.csv               ← GSC からエクスポートしたCSV
│   └── expected_pv.csv       ← 自分で記入する目標PVファイル
├── output/
│   └── report.csv            ← 実行後にここへ出力される
├── src/
│   ├── main.py               ← 集計スクリプト
│   └── check_report.py       ← ターミナルで結果を確認するスクリプト
├── requirements.txt
└── README.md
```

## ─────────────────────────────────
## expected_pv.csv の書き方
## ─────────────────────────────────

### このファイルは何？

「この記事は今月 ○○ PV を目標にする」という目標値を  
**自分で手入力する唯一のファイル**です。  
GA4・GSC とは違い、ツール側で自動エクスポートできないため、  
初回だけ自分で作り、以後は数字を更新して使い続けます。

---

### 書き方：ステップごとに説明

**STEP 1: ファイルを開く**

```
input/expected_pv.csv
```

をダブルクリックして Excel（または テキストエディタ）で開きます。

---

**STEP 2: 1行目（ヘッダー行）は絶対に変えない**

```
article_url,monthly_expected_pv
↑ この行はそのまま残す。削除・編集禁止。
```

---

**STEP 3: 2行目以降に記事を1行1記事で入力する**

```
A列（article_url）           B列（monthly_expected_pv）
────────────────────────────────────────────────────
https://example.com/記事1    1500
https://example.com/記事2    1000
https://example.com/記事3     600
```

- **A列**: 記事の完全 URL を貼り付ける（GA4・GSC の URL と完全一致させること）
- **B列**: その記事の月間目標PV を数字だけ入力（単位・カンマ・スペース不要）

---

### 記入例（完成形）

```csv
article_url,monthly_expected_pv
https://example.com/article-seo-tips,2000
https://example.com/article-how-to-write,1500
https://example.com/article-tools-review,800
```

---

### よくある記入ミスと対処

| ミス | 正しい書き方 |
|---|---|
| `1,500` とカンマ入り | `1500` |
| `1500PV` と単位付き | `1500` |
| URL の末尾に `/` あり・なしが混在 | GA4/GSC のURLと完全一致させる |
| URL が `http://` と `https://` で違う | どちらかに統一する |
| B列が空欄 | 必ず数字を入力する（わからなければ `0` でも可） |

---

### URLの確認方法（GA4と一致しているか確かめたい場合）

1. GA4 にログインし、「レポート → エンゲージメント → ページとスクリーン」を開く
2. 対象記事の「ページパス」列をコピー
3. サイトのドメインを先頭に付けて `https://yourdomain.com/ページパス` の形にする
4. それを `article_url` 列に貼り付ける

## 実行方法
## ─────────────────────────────────

### 前提：Python のインストール

Python 3.10 以上が必要です。  
インストール済みか確認する場合はターミナルで:

```bash
python --version
```

`Python 3.x.x` と表示されれば OK です。

---

### 実行コマンド（毎回これだけ）

プロジェクトルートのフォルダでターミナルを開き、以下を実行します:

```bash
python src/main.py
```

以下のように表示されれば成功です:

```
=== CSV集計レポート生成 ===
読込: .../input/ga4.csv
読込: .../input/gsc.csv
読込: .../input/expected_pv.csv

出力完了: .../output/report.csv
行数: 10 記事
```

## ─────────────────────────────────
## report.csv の確認方法
## ─────────────────────────────────

生成された `output/report.csv` は3通りの方法で確認できます。  
**最もかんたんなのは方法①です。**

---

### 方法① Excel でダブルクリックして開く（最もかんたん）

1. `output/report.csv` をダブルクリック
2. Excel が開く

> **文字化けした場合**（列が崩れたり、文字が `?` になる場合）:
>
> 1. Excel の「データ」タブ →「テキストまたは CSV から」をクリック
> 2. `report.csv` を選択
> 3. 「ファイルの元の文字コード」を **65001: Unicode (UTF-8)** に変更
> 4. 「読み込む」をクリック

---

### 方法② Google スプレッドシートで開く

1. Google スプレッドシートを新規作成
2. 「ファイル」→「インポート」をクリック
3. 「アップロード」タブで `output/report.csv` をドラッグ＆ドロップ
4. 「区切り文字の種類」: **カンマ**（自動検出でも可）
5. 「インポート」をクリック

毎月同じスプレッドシートに上書きしたい場合は「既存のシートを置き換える」を選択。

---

### 方法③ ターミナルで手軽に確認する（Excel を開かずに数値だけ見たい場合）

## output/report.csv の列一覧

| 列名 | 内容 | 補足 |
|---|---|---|
| `article_url` | 記事URL | 主キー |
| `PV` | ページビュー数 | GA4 |
| `期待PV` | 当月経過日数ベースの期待PV | 日割り計算 |
| `PV差分` | PV − 期待PV | プラスなら順調 |
| `増減率` | (PV − 期待PV) / 期待PV | 例: 0.1 = +10% |
| `ペース比` | PV / 期待PV | 1.0 以上なら達成ペース |
| `ランク` | ペース比の高い順の順位 | 1 が最優秀 |
| `アクティブユーザー` | アクティブユーザー数 | GA4 |
| `平均エンゲージメント` | 平均エンゲージメント時間（秒） | GA4 |
| `エンゲージ評価` | 高／中／低 | 120秒以上＝高、60〜120秒＝中、60秒未満＝低 |
| `イベント数` | イベント数 | GA4 |
| `キーイベント` | キーイベント数 | GA4 |
| `インプレッション` | 検索インプレッション数 | GSC |
| `記事クリック数` | 検索クリック数 | GSC |
| `CTAクリック数` | CTAボタンのクリック数 | GA4 |
| `記事CTR` | 検索クリック率 | GSC（例: 0.073 = 7.3%） |
| `掲載順位` | 検索平均掲載順位 | GSC |

---

## 期待PV の計算式（参考）

```
期待PV = monthly_expected_pv × (当月の経過日数 / 当月の日数)
```

例: 月間期待PV が 1,500 で、4月22日（30日中22日経過）の場合
```
期待PV = 1500 × (22 / 30) ≒ 1100
```

## よくあるエラーと対処法

### `FileNotFoundError: input/ga4.csv が見つかりません`

**原因**: ファイルが `input/` フォルダに置かれていない  
**対処**: `input/ga4.csv`（または `gsc.csv` / `expected_pv.csv`）を配置してから再実行

---

### `KeyError: '列名'`

**原因**: CSVの列名がスクリプトの候補リストに一致しない  
**対処**: `src/main.py` の `GA4_COLUMN_MAP` / `GSC_COLUMN_MAP` / `EPV_COLUMN_MAP` に  
実際の列名を追記してください

---

### 結果が 0 ばかりになる

**原因**: 数値列に文字列や単位が混入している（例: `1,200` や `1200回`）  
**対処**: CSVを開いてカンマや単位を取り除いてから再実行

---

### article_url が突合されない（全行の数値が 0 になる）

**原因**: URL の末尾スラッシュや `http/https` の違い  
**対処**: 3ファイルの URL 表記を統一する（スクリプトは前後空白のみ自動除去）

---

### Excel で開くと文字化けする

**原因**: CSV が UTF-8 で保存されているが、Excel がShift-JISと誤認識している  
**対処**: 「データ → テキストまたはCSVから」で開き直し、文字コードを UTF-8 に指定

---

### CTAクリック数のイベント名を変更したい

`src/main.py` の先頭にある `CTA_COLUMN_CANDIDATES` リストに新しい列名を追加してください:

```python
CTA_COLUMN_CANDIDATES = [
    "CTAクリック数",
    "新しいイベント名",   # ← ここに追加
    ...
]
```

## 毎月の運用フロー（まとめ）

```
1. GA4 から CSVエクスポート → input/ga4.csv に上書き保存
2. GSC から CSVエクスポート → input/gsc.csv に上書き保存
3. input/expected_pv.csv の数字を必要に応じて更新
4. ターミナルで python src/main.py を実行
5. output/report.csv を Excel / スプレッドシートで開いて確認
   （またはターミナルで python src/check_report.py）
```
