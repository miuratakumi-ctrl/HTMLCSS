# 目覚ましアプリ

ブラウザだけで動く目覚まし時計です。`alarm/index.html` をダブルクリックして開くだけで使えます
（サーバーやインストールは不要）。

## 機能

- 現在時刻・日付の表示
- 時刻を指定してアラームを追加（ラベル付き）
- 曜日の繰り返し設定（未選択なら1回だけ鳴って自動オフ）
- 各アラームのオン/オフ切り替え・削除
- 鳴動画面で「停止」または「スヌーズ（5分後）」
- 設定は localStorage に保存されるので、閉じても残ります

## 注意

- ブラウザのタブを閉じるとアラームは鳴りません。開いたままにしてください。
- 音は Web Audio API のビープ音です。ページを一度もクリックしていないと
  ブラウザの自動再生制限で音が出ないことがあります（画面表示は出ます）。
